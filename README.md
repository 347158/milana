## Gebruik

### Openen
Open `index.html` in je browser of gebruik een lokale server:

```bash
# Met Python
python -m http.server 8000

# Met Node.js (npm)
npx serve
```

### Aanpassen

1. **Persoonlijke gegevens**: Wijzig je naam en beschrijving in `index.html`
2. **Kleuren**: Pas de CSS variabelen aan in `css/style.css`:
   ```css
   :root {
       --color-primary: #2563eb;    /* Hoofdkleur */
       --color-text: #1f2937;       /* Tekstkleur */
       --color-bg: #ffffff;         /* Achtergrond */
   }
   ```
3. **Projecten**: Voeg je eigen projecten toe aan de projecten-sectie
4. **Afbeeldingen**: Vervang de placeholder afbeeldingen in `images/`

## Ontwikkelproces met OpenCode

De projectenpagina is ontwikkeld met hulp van OpenCode. Hieronder het proces dat is doorlopen:

### 1. Analyseren
OpenCode heeft eerst de bestaande projectstructuur en code onderzocht. Er werden nog geen bestanden aangepast.

### 2. Specificeren
OpenCode stelde vragen over de gewenste projectenpagina, navigatie, vormgeving, mobiele weergave en filters. Daarna is een specificatie gemaakt.

### 3. Plannen
Er is een implementatieplan gemaakt met kleine stappen voor HTML, CSS en JavaScript.

### 4. Bouwen
- De projectenpagina `projects.html` is toegevoegd.
- De navigatie is aangepast.
- CSS en JavaScript zijn aangepast.
- Daarna zijn de voorbeeldprojecten vervangen door mijn 3 echte projecten.

### 5. Controleren
- Ik heb de website zelf in de browser gecontroleerd.
- Ik heb de navigatie en filters getest.
- De filters Alles, HTML, CSS, JavaScript en Python zijn gecontroleerd.
- De mobiele navigatie is gecontroleerd.

### 6. Eigen keuzes
- Ik heb de voorstellen van OpenCode gecontroleerd voordat ze werden gebruikt.
- Voorbeeldprojecten zoals een To-do lijst en Python-project zijn niet gebruikt, omdat dit geen echte projecten van mij waren.
- Ik heb de projectinhoud vervangen door mijn eigen echte projecten.
